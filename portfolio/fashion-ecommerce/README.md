# FASHION — E-COMMERCE

Коммерческий AI-проект: съёмка спортивного костюма для карточки товара на маркетплейсе.

Бренд не указан. Брюки имеют регулируемые манжеты и могут носиться как свободными, так и собранными снизу.

Загрузить 7 изображений серии в эту папку, назвав их `1.jpg`–`7.jpg` в выбранном порядке.

После загрузки изображений добавить проект в галерею `preview.html`. Основную страницу `index.html` не изменять.
