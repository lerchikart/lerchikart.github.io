# FASHION — E-COMMERCE

Коммерческая AI-съёмка спортивного костюма для карточки товара на маркетплейсе. Название бренда не указано.

Особенность брюк: регулируемый низ — можно носить с прямыми широкими штанинами или затянуть манжеты.

Обложка галереи: `1.jpg`.

На данный момент в папке шесть изображений: `1.jpg`, `2.jpg`, `4.jpg`, `5.jpg`, `6.png`, `8.jpg`. Файл `3` отсутствует; после его загрузки галерею можно дополнить до семи кадров.
