# Видео для портфолио LERCHIKART

Загружайте сюда оригинальные файлы видео в формате `.mp4` (H.264). Для каждого видео используйте понятное уникальное имя (например, `daydesign.mp4`, `demix.mp4`). Не удаляйте и не переименовывайте уже загруженные файлы без необходимости.

После загрузки видео заменим ссылки Rutube на локальные видео в `preview.html` и проверим воспроизведение.

Через браузер GitHub загружаются файлы до 25 МиБ. Более крупные видео необходимо сжать либо выбрать отдельный видеохостинг.
